# Usage de l'IA

## Outils utilisés
- Claude Code (Anthropic)

## Tâches confiées
- Mise en place de la structure du projet selon le template.
- Implémentation du modèle Pydantic et des règles de normalisation.
- Écriture du script de collecte asynchrone avec `crawl4ai`.
- Rédaction des tests de vérification offline.

## Exemples de prompts
- "Help me implement the Product model for S19 with Decimal price normalization."
- "Create a robust extraction logic for the automation exercise products page."

## Vérifications effectuées
- J'ai vérifié que les sélecteurs CSS correspondent bien à la structure HTML de la cible.
- J'ai testé la normalisation des prix avec plusieurs formats (virgule, point, symboles).
- J'ai validé que le code respecte les règles de `robots.txt` et de délai.
